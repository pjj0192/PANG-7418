# 게임 룰 상세

`docs/PRD.md`에 정의된 규칙을 오브젝트/시스템 단위로 상세화한 문서.

## Player

- 조작: 키보드 방향키 좌/우 버튼으로 좌우 이동만 가능(상하 이동 없음)
- Wire 발사: Space 키 입력 시 현재 위치에서 수직 위쪽으로만 발사
- 피격: Bubble에 접촉하면 목숨 1개 차감, 초기 목숨은 5개
- 무적/피격 후 처리: 목숨 차감 시 2.5초간 무적 상태 부여(무적 중에는 Bubble에 접촉해도 추가 피격 없음)

## Wire

- 발사 방향: 항상 수직 위쪽 고정 (좌우 조준 불가)
- 발사 제한: 화면에 하나의 Wire만 존재 가능(동시 다발 발사는 이후 파워업 범위)
- 충돌 처리:
  - Bubble에 명중 시 해당 Bubble을 2개의 더 작은 Bubble로 분할
  - 가장 작은 크기의 Bubble에 명중 시 해당 Bubble은 소멸(분할 없음)
  - 벽(화면 좌우 경계)에 닿으면 Wire는 소멸, 벽을 뚫고 나가지 않음
  - 화면 상단에 닿아도 더 이상 진행하지 못하고 소멸

## Bubble

- 이동: 좌/우 방향으로 공처럼 튕기며 이동
- 물리: 중력의 영향을 받아 낙하하며, 바닥/Block에 튕길 때마다 직전과 동일한 높이까지 다시 튀어오름(에너지 손실 없음)
- 크기 단계: 큰 Bubble → Wire에 맞으면 중간 크기 2개로 분할 → 다시 맞으면 작은 크기 2개로 분할 → 가장 작은 크기는 Wire를 맞으면 완전히 소멸
- 경계 처리: 화면 좌우 경계를 벗어날 수 없으며, 벽에 닿으면 방향이 반전됨
- 화면 밖으로 나갈 수 없음(상/하/좌/우 모두 화면 내에서만 움직임)
- 아이템 드롭: Wire에 맞아 소멸(분할 포함)할 때마다 20% 확률로 아이템 1개를 드롭. 아이템 종류는 추후 결정

## Block

- 특징: 파괴 불가능한 고정 오브젝트(벽과 동일하게 부서지지 않음)
- Bubble과의 상호작용: Bubble이 Block 표면(위쪽 등) 위로 튕겨 올라갈 수 있음
- Wire와의 상호작용: Wire는 Block을 통과하지 못하고 막힘(벽과 동일한 처리)

## 승리/패배 조건

- **승리**: 화면 내 모든 Bubble이 소멸된 경우 스테이지 클리어
- **패배**: Player의 목숨이 0이 되면 게임 오버

## 범위 밖(추후 결정)

- 파워업 아이템(더블 Wire, 화력 강화 등)
- 2인 협동 플레이
- 스테이지 진행/셀렉트, 점수 및 랭킹 시스템
- 제한 시간 존재 여부
