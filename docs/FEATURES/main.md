# 메인 화면 구성

## 목적

게임 실행 시 최초로 보여지는 화면. 플레이어가 게임을 시작하거나 조작법을 확인할 수 있는 진입점 역할.

## 화면 구성 요소

- **타이틀 로고**: "PANG" 게임 제목을 화면 상단 또는 중앙에 표시
- **시작 버튼**: 클릭 또는 Enter/Space 키로 Mission 1 게임 화면으로 진입
- **조작법 안내**: 방향키(이동), Space(Wire 발사) 등 기본 조작키 안내 문구
- **버전/크레딧 정보**: 하단에 간단히 표기 (선택 사항)

## 화면 흐름

1. 앱 진입 시 메인 화면이 기본으로 표시됨
2. 시작 버튼 클릭(또는 지정 키 입력) 시 Mission 1 플레이 화면으로 전환
3. 게임 오버 또는 스테이지 클리어 후 메인 화면으로 돌아올 수 있는 동선 고려(추후 구현)

## Mission 1 범위에서의 스코프

- 타이틀 + 시작 버튼 + 조작법 안내 정도의 정적 화면으로 최소 구현
- 메뉴 애니메이션, 배경음악, 옵션(난이도 선택, 사운드 설정) 등은 이후 범위로 둠
