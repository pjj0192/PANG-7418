# Mission 1 - 난이도 및 규칙

## 목적

팡 게임의 첫 스테이지를 웹으로 구현하는 최초 미션. 튜토리얼 성격의 낮은 난이도로 핵심 게임 루프(이동, 발사, Bubble 물리, 충돌, 승패 판정)를 검증하는 것이 목표.

## 난이도 구성

- **Bubble 개수**: 시작 시 큰 Bubble 1~2개만 배치 (분할로 늘어나는 것 포함해도 화면 내 동시 Bubble 수는 소수로 유지)
- **Bubble 크기 단계**: 큰 → 중간 → 작은(3단계), 작은 단계에서 Wire에 맞으면 소멸
- **Block 배치**: Mission 1에서는 Block(장애물) 없이 좌/우 벽과 바닥만 존재하는 단순한 스테이지로 시작
- **제한 시간**: 없음(모든 Bubble을 소멸시킬 때까지 시간 제약 없이 플레이)

## 규칙 (game_rule.md 기준 적용)

- Player는 좌/우 이동만 가능, Wire는 수직 위쪽으로만 발사
- Bubble에 닿으면 목숨 1개 차감, 초기 목숨 5개, 차감 시 2.5초간 무적
- 목숨이 0이 되면 게임 오버, 모든 Bubble 소멸 시 스테이지 클리어
- Bubble은 중력의 영향을 받아 튕기며, 벽 밖으로 나가지 않음
- Bubble이 Wire에 맞아 소멸할 때마다 20% 확률로 아이템 드롭(종류는 추후 결정)

## 진행/종료 처리

- **클리어**: 모든 Bubble 소멸 시 클리어 화면(또는 메시지) 표시 후 메인 화면으로 복귀 가능
- **게임 오버**: 목숨 소진 시 게임 오버 화면(또는 메시지) 표시 후 메인 화면으로 복귀 가능
- 다음 스테이지(Mission 2 이상) 연결은 이번 범위에 포함하지 않음

## Mission 1 이후로 미루는 것

- Block(장애물) 배치가 있는 복잡한 스테이지 구성
- 파워업 아이템
- 2인 협동 플레이
- 점수/랭킹 시스템, 스테이지 셀렉트
- 제한 시간 도입
